# Catalog

## Overview

The catalog is a private Vite gallery. It installs `@house/tokens` and `@house/react` the way a consuming app does, and it loads the four Fontsource faces the presets name.

## Key files

| File | Owns |
|---|---|
| `src/App.tsx` | Preset switcher and the gallery |

## Commands

```bash
npm run dev -w catalog
npm test -w catalog
```

## Conventions

- Follow the root rules.
- Stay clears `data-preset`. The other looks set it.
